# HB Continuum v1.1.0

A stable, source-only release for personal use. The archival core and storage
formats of the 1.x series are unchanged in spirit; this release adds acquisition
reliability, per-folder visibility and OAuth2 for providers that refuse
password logins.

Not included: unsigned or signed installers, Linux/Windows desktop artifacts,
OCR, streaming AI output, semantic retrieval, entity graphs, dossiers or an MCP
server. The
[implementation inventory](../engineering/IMPLEMENTATION_STATUS.md) is the
authority on what exists, and each claim below is checked against it in CI.

## Highlights

- **Incremental synchronization.** Each folder records its UIDVALIDITY and the
  last UID seen. A matching run asks the server only for newer messages; a
  changed UIDVALIDITY logs a warning, resets that folder and rescans with the
  existing SHA-256 deduplication. <!-- claim: incremental-sync -->
- **Per-folder coverage.** `dispatch.py health` reports, for every folder, how
  many messages the server holds, how many the archive holds and how many are
  missing, so an incomplete download is visible instead of assumed complete.
  <!-- claim: folder-coverage -->
- **Run checkpoints.** Every folder run is recorded before the network is
  touched and closed as `ok` or `error` with the last ingested UID, so an
  interrupted sync is auditable and resumes rather than replays.
  <!-- claim: sync-checkpoints -->
- **OAuth2 for Microsoft and Google.** A loopback PKCE flow with your own
  desktop client ID, authenticating IMAP with `XOAUTH2`. Refresh tokens are
  written only to an operating-system credential store; a missing or plaintext
  file keyring is refused. <!-- claim: oauth-pkce -->
- **Provider presets.** Gmail, iCloud, Fastmail, IONOS, Outlook/Microsoft 365
  and Custom, each stating what it actually requires.
  <!-- claim: imap-presets -->
- **MBOX interoperability.** Import with reconstruction provenance kept distinct
  from original EML, preview with counts and problems, and export with overwrite
  protection and a plaintext warning. <!-- claim: mbox-import -->
- **Verified migration snapshots.** Each pre-upgrade database copy is opened
  read-only, integrity-checked and hashed before the report claims a backup.
  <!-- claim: migration-snapshot -->

## Schema

Archive schema is **8**: `imap_folder_state` (7), `sync_checkpoints` (8).
Upgrades are transactional, one version per transaction, and refuse to open a
database written by a newer build. A copy of each database is written before the
upgrade and verified afterwards. Existing 1.0.0 archives upgrade in place.

## Verification

- 457 Python tests pass on Python 3.12 (24 skipped without `sqlcipher3`).
- CI runs the suite on Linux, macOS and Windows, a dedicated encryption job that
  installs SQLCipher and executes the security vector script on two platforms,
  plus `mypy` and a documentation-fidelity guard that fails when a release note
  claims something the inventory does not record.
- A migration drill from schema 6 to 8 on plaintext and SQLCipher archives
  confirmed no message or full-text loss, and that an encrypted snapshot cannot
  be opened by ordinary SQLite.

## Known limits

- Encryption covers the three SQLite databases only. Raw EML under `raw/`,
  external documents at their original paths, preferences, exports, reports and
  logs remain plaintext. Use full-disk encryption as well.
- The desktop application is qualified on macOS Apple Silicon only; no Linux or
  Windows desktop build is produced or claimed.
- OAuth tokens are refreshed manually: an expired access token is not renewed
  inside `sync` yet, and there is no desktop UI for the flow.
- A full-archive snapshot through `backup.py` before a schema upgrade is not
  implemented; per-database copies are.
- Retrieval is keyword/FTS5, not semantic. Model output is not evidence.
- The `glib` advisory reachable through Tauri's Linux-only GTK dependency is
  dismissed as not-used, because no Linux desktop artifact is shipped.
- No independent security audit has been performed.

Do not use HB Continuum as the sole copy of irreplaceable evidence.
